# RePanel — калькуляторы и прайс-лист внутри сайта

**Дата:** 2026-06-08
**Статус:** Согласован дизайн, ожидает ревью спецификации
**Репозиторий:** `repanel-site` (Next.js 16, React 19, Tailwind 4, TypeScript)

## Контекст и цель

Три самых частых запроса клиентов — «рассчитать столешницу», «прикинуть бюджет проекта», «прайс-лист» — сейчас живут как **внешние ссылки** на отдельное Flask-приложение (`RePanel calculator`, маршруты `/countertop`, `/calculator`, `/prices`). Цель — **перенести эти инструменты нативно внутрь сайта** в фирменном дизайне RePanel, без зависимости от аптайма Flask-приложения для самих расчётов.

Вся клиентская логика уже существует в JS и переиспользуется при портировании:
- `prices_calc.js` (~14 КБ) — расчёт цен и расчёт по площади
- `countertop_calc.js` (~115 КБ) — раскрой столешницы (формы, упаковка в листы, триангуляция)
- Внутренний `calculator.js` (~546 КБ, CRM) — **не трогаем**.

Источник цен и формул: `RePanel calculator/config.py`, `app.py` (`_public_sheet_prices_payload`, `SHEET_MARGIN_TIERS`), `countertop_pdf_generator.py`.

## Согласованные решения (из брейншторма)

| Вопрос | Решение |
|---|---|
| Что такое «бюджет проекта» | **Оба**: быстрая вилка по типу проекта + точный расчёт по м² |
| Цены на сайте | **Точные**, публично (как на текущей `/prices`) |
| Результат расчёта | **Цена на экране + PDF-смета + заявка** |
| Архитектура | **Нативно**: логика в TS в браузере, цены — снапшот в репо |
| Структура | **Единый `/calculator` с вкладками** + отдельный `/prices` |
| Формы столешницы | Прямая / L / П — достаточно |
| **Фартук** | Добавить в калькулятор столешницы (частый запрос) — **новая фича** |
| Схема раскроя | Показываем клиенту (плюс для архитекторов) |
| Главная цена в прайсе | **₽/м²** крупно, по ступеням объёма; цена за лист — приглушённо рядом |
| Палитра в прайсе | Да; явно: вне палитры — доплата |
| Скидки за объём | Показываем конкретные ступени |
| PDF | **Переиспользуем готовый брендированный PDF** из Flask-приложения |

## Структура и навигация

- **`/calculator`** — единый калькулятор, 3 вкладки:
  1. **Столешница** — форма (□/L/П), размеры, вырезы, фартук, толщина/материал/цвет/сборка → схема раскроя + цена
  2. **По площади** — площадь × толщина × материал × цвет → цена
  3. **По типу проекта** — выбор типа → вилка «от–до»
- **`/prices`** — прайс-лист (₽/м² по объёму + цена за лист + палитра + PDF)
- **Навигация:** в меню добавить пункты **«Калькулятор»** и **«Цены»** (`src/components/Header.tsx`, массивы `navItems` и мобильное меню). Кнопку-CTA в шапке «Получить расчёт» → **«Рассчитать →»** на `/calculator`.
- **Глубокие ссылки:** на страницах решений (`/solutions/horeca`, `/solutions/retail` и т.д.) — кнопка «Рассчитать столешницу» с переходом сразу на нужную вкладку (через query, напр. `/calculator?tab=countertop`).

## Архитектура

Нативные страницы Next.js. Расчёт выполняется целиком на клиенте чистыми TS-функциями — сайт не зависит от Flask для отображения цен и расчётов. Единственная точка обращения к Flask — кнопка скачивания PDF (см. ниже).

### Данные о ценах — снапшот в репозитории

- Файл **`src/data/prices.json`** — снимок публичных цен.
- **Генерируется из текущего публичного источника** `GET /api/public/sheet_prices` Flask-приложения (или из его функции `_public_sheet_prices_payload`), чтобы цифры совпадали с тем, что клиенты видят сейчас.
- **Из снапшота вырезаем себестоимость** (`cost_per_sqm`) — публично не показываем. Оставляем: `thickness_mm`, `format`, `area_sqm`, `weight_per_sqm_kg`, `price_no_vat`, `price_with_vat`, `margin_tiers[]` (цена по объёму), `material_type`, `updated_at`, `vat_rate`.
- Обновление — скрипт **`npm run sync-prices`** (Route Handler или node-скрипт, тянет публичный payload и переписывает `prices.json`). Цены меняются редко — ручной запуск приемлем.

### Ключевые ценовые константы (для справки, источник истины — `prices.json`)

- НДС: **5%** (добавляется сверху).
- Объёмные ступени (`SHEET_MARGIN_TIERS`): **1–10 листов 40%** (база) · **11–20 → −10%** · **21–30 → −17%** · **31+ → −24%** (проценты — относительно базовой цены).
- Полупрозрачный материал: **+15%**.
- Цвет: свой под образец **+18 000 ₽**, подбор по RAL **+144 000 ₽** (плоская доплата, без наценки).
- Форматы листа: 500×500 (площадь 0.25 м², ценовой коэффициент 0.40), 1000×1000 (1.0), 2200×1100 (2.42).
- Не продаётся: **2200×1100 в 12/16/40 мм** (скрываем «—»).
- Толщины в прайсе: 12, 16, 20, 30, 40 мм. Толщины столешницы: 20, 30, 40 мм.

## Модули

- **`src/data/prices.json`** — снапшот цен.
- **`src/lib/pricing/`** — движок цен (порт `prices_calc.js`):
  - `sheetPrice(thickness, format, material, qtyTier)` — цена листа/м² с учётом тира, материала, НДС.
  - `areaEstimate({ areaM2, thickness, material, color })` — расчёт по площади.
  - `colorAddon(color)`, `applyVat(x)` — доплаты/НДС.
- **`src/lib/countertop/`** — раскрой (порт `countertop_calc.js`):
  - `computeParts(form, dims)` — детали по форме.
  - `binPack(pieces, sheet)` — упаковка в листы (1000×1000 и 2200×1100, выбор дешевле).
  - `backsplashPieces(dims, height, length)` — **новая** логика фартука (доп. полосы-детали).
  - `countertopEstimate(...)` — итог: листы, площадь, вес, цена, данные для схемы.
- **Компоненты** (`src/components/calculator/`): `CalculatorTabs`, `AreaCalculator`, `CountertopCalculator` (включая `ShapePicker`, `CutoutList`, `BacksplashField`, `LayoutDiagram`), `ProjectTypeEstimator`, `ResultCard` (цена + PDF + заявка), `PriceTable`, `VolumeTiers`, `Palette`.
- **Переиспользуем:** `Header`, `Footer`, `Button`, `ContactForm`, `SectionHeading`, `FAQ`.

## Поток данных

Ввод (состояние React, client component) → чистая функция движка (`src/lib/...`) → результат → `ResultCard`. Из результата: (1) ссылка на PDF с query-параметрами, (2) предзаполнение заявки сводкой расчёта.

## Вкладка «По типу проекта»

Выбор типа проекта → пресет типовой площади поверхностей и толщины → вилка «от–до» тем же движком (`areaEstimate` на нижней/верхней границе площади) → CTA «Уточнить расчёт» / «Оставить заявку».

Черновой список типов: **Кофейня/бар · Ресторан · Ритейл/шоурум · Ресепшен/стойка · Мебель/объект · Жильё**.

> **Открытый вопрос (нужны цифры от заказчика):** типовые диапазоны площади поверхностей и рекомендуемые толщины для каждого типа. Без них вкладка считается по заглушечным пресетам. Уточняется на этапе сборки фазы ④.

## Результат → заявка

`ResultCard` формирует текстовую сводку (инструмент, параметры, расчётная цена) и:
1. Предзаполняет `ContactForm` (поля `need`, `sizes`, `comment` — сводкой и размерами).
2. Дублирует ссылку «написать в Telegram» (`https://t.me/repanel`).

> **Важно:** сейчас `ContactForm` — **нефункциональная заглушка** (нет обработчика `onSubmit`, кнопка ничего не отправляет). В рамках этой работы форму нужно **реально подключить**.
>
> **Открытый вопрос (решение заказчика):** куда падают заявки? Варианты: (a) Next API-route → Telegram-бот (переиспользовать токен из `config_telegram.py` калькулятора); (b) Next API-route → email; (c) POST в новый публичный эндпоинт калькулятора (создаёт лид в CRM + уведомляет Telegram). Рекомендация для MVP — (a) или (c).

## PDF-смета (переиспользование Flask)

Кнопка «Скачать PDF» ведёт на готовые брендированные эндпоинты Flask-приложения с query-параметрами, повторяющими ввод на экране:
- По площади: `/calculator/estimate.pdf?area=&thickness=&material=&color=`
- Столешница: `/countertop/estimate.pdf?form=&<dims>&cutouts=&material=&thickness=&color=&assembled=`
- Прайс: `/prices.pdf`

Базовый URL приложения — в env (`NEXT_PUBLIC_CALC_BASE_URL`).

> **Зависимость для фартука:** текущий `/countertop/estimate.pdf` **не знает про фартук**. Чтобы фартук попал в PDF, нужно либо (a) расширить Flask-эндпоинт и `countertop_pdf_generator.py` параметрами фартука, либо (b) передавать фартук как дополнительные прямоугольные детали, которые понимает текущий упаковщик. Решается в фазе ③.

## Обработка краёв (edge cases)

- Пустые/нулевые/нечисловые поля → цена не считается, мягкая подсказка.
- Недопустимая пара формат×толщина → скрыта/«—».
- Деталь столешницы больше листа → авто-разбиение упаковщиком; если не помещается даже частями → сообщение.
- Фартук выключен → не учитывается.
- Очень большой объём → верхний тир (31+).
- Нестандартная толщина в публичном UI не предлагается (только из списка).

## Тестирование

- Юнит-тесты движка цен и `areaEstimate` — сверка с эталонными значениями (прогон тех же входов через Python/JS-референс).
- Тесты `countertop` — площади и число листов для известных форм (прямая/L/П, с фартуком и без).
- Тест схемы `prices.json` (валидность, нет `cost_per_sqm`).
- Смоук-рендер компонентов; проверка мобильной раскладки (колонки складываются, результат «прилипает» снизу).

## Порядок сборки (фазы)

1. **Движок цен + `prices.json` + страница `/prices`** (прайс-таблица, палитра, PDF-ссылка).
2. **Вкладка «По площади» + `ResultCard` + заявка** (подключение формы) **+ PDF-ссылка**.
3. **Вкладка «Столешница»** (порт `countertop_calc.js`) + **фартук** + схема раскроя + доработка PDF под фартук.
4. **Вкладка «По типу проекта»** (после получения пресетов от заказчика).
5. **Навигация и CTA** (Header, кнопка в шапке) + глубокие ссылки со страниц решений.
