## Основание и цель

Выполнен перенос минимально необходимого набора клиентских данных RePanel в
базу данных на территории Российской Федерации для выполнения требований
части 5 статьи 18 Федерального закона № 152-ФЗ.

Целевой контур:

- YDB Serverless `repanel-personal-data`;
- регион `ru-central1`;
- приложение в Yandex Serverless Containers;
- публичный адрес российского приложения `https://site.re-panel.ru`.

## Удаление прежних рабочих копий

После переключения сайта удалены записи из активных таблиц прежней рабочей
базы:

- `order_timeline`: удалено 4, остаток 0;
- `returns`: удалено 0, остаток 0;
- `certificates`: удалено 0, остаток 0;
- `shop_orders`: удалено 2, остаток 0.

После удаления выполнена повторная проверка:

- все четыре набора в прежней рабочей базе содержат 0 записей;
- российская административная панель отвечает успешно;
- в YDB доступны 2 заказа.

Каталог, публичные изображения и промокоды не удалялись, поскольку не содержат
клиентских персональных данных. Локальная резервная копия удалённых записей не
создавалась.

Проверку договорных сроков хранения технических резервных копий на стороне
прежнего поставщика следует включить во внутренний контроль оператора.
